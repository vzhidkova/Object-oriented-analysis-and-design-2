# Стратегия 
## Зачем нужен паттерн
В программе есть несколько видов транспорта для которого вычисляется маршрут и время на его прохождение. Применние паттерна хорошо для учета будующих изменений, если в будующем различия между способами передвижения станут больше, наличие паттерна стратегия будет очень полезно
