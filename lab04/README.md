# Паттерн Lazy Loading
Задача: приложение для хранения проектов с древовидной структурой
Как применяется паттерн: информация о задачах и их подзадачи запрашиваются из БД только когда с ними начинают работать
Почему паттерн нужен: при условии если БД большая загружать все сразу неэффективно и расходует много памяти (╥_╥) грустно печально
